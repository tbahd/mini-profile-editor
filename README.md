# Mini Profile Editor (React)

A simple React project built to practice **controlled inputs**, **state management**, and **real-time UI updates**.

This project demonstrates how form inputs are controlled by React state and how user input can be reflected instantly in the UI.

---

## Live Preview
https://mini-profile-editor.netlify.app/

## 🚀 Features

* Name input field (controlled)
* Bio textarea (controlled)
* Live preview of profile details
* Clear profile button
* Clean, responsive UI styled with Tailwind CSS

---

## 🧠 Concepts Practiced

* React `useState` hook
* Controlled components
* Handling input changes with `onChange`
* Syncing form state with UI
* Conditional rendering for empty states
* Component-level state management

---

## ▶️ How It Works

* Input values are stored in React state
* Each input is controlled using the `value` and `onChange` props
* As the user types, state updates trigger automatic UI re-renders
* A live preview displays the current state values
* The clear button resets all state and input fields
